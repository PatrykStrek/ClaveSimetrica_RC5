	\section{Introducción}
	El algoritmo de simétrico RC5 fue diseñado por Ronald Rivest en 1994, permitiendo cifrar y descifrar información mediante el uso de una clave secreta compartida entre los usuarios que lo empleen.
	A continuación, explicaremos el funcionamiento, características y proceso de cifrado/descifrado de la implementación de este algoritmo en Python que hemos desarrollado.
	% -------------------------------------------------
	% 2. Explicacion RC5
	% -------------------------------------------------
	
	\section{¿Qué es?}
	RC5 es un algoritmo de cifrado de clave simétrica diseñado por Ronald Rivest. Se caracteriza por su sencillez y flexibilidad, ya que permite configurar el tamaño de palabra, el número de rondas y la longitud de la clave usada.
	Este algoritmo se basa en 3 operaciones principales:
	\begin{enumerate}
		\item La suma modular
		\item XOR
		\item Las rotaciones de bits dependientes de los datos.
	\end{enumerate}
	De esta forma, la combinación de estas 3 operaciones permite transformar el mensaje original en un texto cifrado que no puede interpretarse directamente sin disponer de la clave correcta.
	\subsection{Características principales}
	\begin{itemize}
		\item Se usa una clave secreta para realizar tanto el cifrado como el descifrado.
		\item Sus parámetros permiten adaptar el algoritmo a diferentes necesidades. Se suelen expresar como RC5-w/r/b: 
		\begin{itemize}
			\item w: tamaño de las palabras en bits.
			\item r: número de rondas.
			\item b: longitud de la clave en bytes.
		\end{itemize}
		\item Antes de cifrar, la clave se procesa para generar una tabla de subclaves que se utilizarán durante las distintas etapas de RC5.
	\end{itemize}

	\subsubsection{Proceso de cifrado y de descifrado}
	El cifrado comienza dividiendo el bloque de entrada en 2 palabras. A continuación, se aplican operaciones con las subclaves y una serie de rondas en las que se combinan sumas modulares, XOR y rotaciones de bits. Como resultado, queda un bloque cifrado de la misma longitud que el bloque original.
	Para el descifrado, se realizan las operaciones inversas, empleando las subclaves en orden inverso, para recuperar las palabras originales y reconstruir el mensaje original.
	
	\subsection{Generación y expansión de claves}
	En RC5 utilizamos un proceso de expansión de claves para transformar la clave secreta original en una tabla de subclaves. Estas subclaves se emplean a lo largo de las distintas etapas del cifrado y permiten que las operaciones dependan de la clave proporcionada.
	El proceso consta de 3 fases:
	\begin{itemize}
		\item Inicialización de la tabla de subclaves: se crea una tabla S con 2(r+1) elementos, donde r es el número de rondas del algoritmo. Esta tabla se inicializa mediante una secuencia de constantes matemáticas.
		\item Preparación de la clave: los bytes de la clave original se agrupan en palabras de w bits, almacenándose en una tabla auxiliar L.
		\item Mezcla de las tablas: se combinan repetidamente los elementos de las tablas S y L mediante sumas modulares y rotaciones de bits. De esta manera, obtenemos una tabla de subclaves dependiente de la clave original (y de los parámetros elegidos para RC5).
	\end{itemize}
	Una vez completado este proceso, la tabla S contiene las subclaves necesarias para realizar el cifrado y descifrado.

	\section{Manual de usuario}
	El programa para cifrar con RC5 muestra una pantalla principal en la que el usuario puede elegir si cifrar, descifrar, la clave que quiere utilizar para llevar a cabo el cifrado/descifrado y, finalmente, si quiere cifrar usando ECB o CBC. \\
	
	Tanto el texto a cifrar como la clave que se usará para ejecutar el algoritmo se escriben en texto plano, devolviendo el texto cifrado en hexadecimal. \\
	
	Cuando el usuario quiere descifrar el texto, el texto a introducir se introduce en hexadecimal y la clave se introduce igual en texto plano. El programa devuelve el texto descifrado en texto plano.\\
	
	Además, para poder transmitir de manera sencilla la información, el programa ofrece la opción de copiar el texto.\\
	
	A continuación se detallan las distintas pruebas de ejecución del programa, indicando como usar cada una de sus funciones.\\
